# Validation checklist

- [ ] Detection records language, framework, domain, architecture, file count, and all routes.
- [ ] Audit has at least eight technology-agnostic checks and exact locations.
- [ ] Findings are severity sorted and include deprecated API detection.
- [ ] Human approval is recorded before application edits.
- [ ] Application syntax/import checks pass.
- [ ] Application boots on an isolated port or test client.
- [ ] Every original endpoint is exercised with a representative success/failure case.
- [ ] Response keys and status codes are unchanged unless explicitly approved.
- [ ] Report records commands, exit codes, and runtime evidence.
